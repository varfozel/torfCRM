# Peat CRM (Торф CRM)

Легка, надійна та практична CRM-система й модуль управління доставками для невеликого сімейного підприємства з видобутку та реалізації торфу в Україні.

---

## 🛠 Технологічний стек

- **Python 3.12+**
- **FastAPI** — асинхронний REST API з автодокументацією OpenAPI (Swagger).
- **PostgreSQL 16** — з точним збереженням фінансових значень через `NUMERIC(10, 2)`.
- **SQLAlchemy 2.0 (async)** + **asyncpg** — сучасний асинхронний ORM.
- **Alembic** — автоматичні міграції структури бази даних.
- **aiogram 3** — швидкий Telegram-бот з FSM-майстрами створення замовлень та клієнтів.
- **Docker & Docker Compose** — ізольоване розгортання на Linux VPS.
- **Pydantic Settings (v2)** — типізована конфігурація середовища.

## 📦 Сутності системи

### 1. Клієнти (`Customer`)
- Повне ім'я / назва підприємства (пошук через `ILIKE`).
- Номер телефону (пошук).
- Адреса вивантаження/реєстрації.
- Опціональні координати (широта, довгота) — підтримується автоматичний парсинг з повідомлень Viber / Google Maps.
- Примітки про клієнта та історія замовлень.

### 2. Замовлення (`Order`)
- Зв'язок із клієнтом (`customer_id`, каскадне видалення).
- Фіксований товар: **«Торф'яний брикет»**.
- Кількість брикету (`quantity`) та ціна за одиницю (`unit_price`).
- Вартість доставки (`delivery_price`, за замовчуванням `0.00 грн`).
- Автоматичний розрахунок загальної суми:
  - `product_total = quantity × unit_price` (вартість товару)
  - `total_amount = product_total + delivery_price` (разом до сплати)
- Адреса вивантаження (автоматично успадковується від клієнта, якщо не вказана інша).
- Статуси доставки:
  - `new` — нове замовлення
  - `planned` — заплановано до виїзду
  - `in_delivery` — водій виїхав на доставку (фіксується час виїзду)
  - `delivered` — доставлено клієнту (фіксується час завершення)
  - `cancelled` — скасовано
- Динамічне посилання навігації **Waze**:
  > **Важливо щодо Waze:** Стандартне URL-посилання Waze запускає маршрутизацію з *поточного місцезнаходження водія* до точки клієнта. Координати базового складу зберігаються централізовано в налаштуваннях для обліку та можливої інтеграції сторонніх розрахунків.

## 🤖 Telegram-бот (aiogram 3)

Бот підтримує спільну бізнес-логіку з REST API (жодного дублювання коду).

### Основні команди:
- `/start` — привітання, інформація про склад та головне меню.
- `/new_customer` — покроковий майстер додавання клієнта з перевіркою телефону та парсингом координат.
- `/customers [запит]` — перегляд останніх клієнтів або швидкий пошук за прізвищем/телефоном (напр. `/customers 067` чи `/customers Ковальчук`).
- `/new_order` — покроковий майстер оформлення замовлення:
  1. Вибір клієнта (за ID, телефоном або ім'ям).
  2. Введення кількості торф'яного брикету.
  3. Введення ціни за одиницю.
  4. Введення вартості доставки (з кнопкою безкоштовної доставки `0 грн`).
  5. Введення адреси доставки або координат.
  6. Перевірка підсумку (товар, сума товару, доставка, разом до сплати).
  7. Підтвердження або скасування створення.
- `/orders [статус]` — перегляд 10 останніх замовлень (напр. `/orders in_delivery` або `/orders new`).
- `/order_ID` (напр. `/order_1`) — детальна картка замовлення з кнопками швидкої дії:
  - 🧭 **Waze** — пряме посилання для навігатора водія.
  - 📍 **Google Maps** — перегляд точки на карті.
  - 🚚 **Почати доставку** — переводить у статус `in_delivery` та фіксує точний час виїзду.
  - ✅ **Доставлено** — завершує доставку та фіксує час вручення.
  - ❌ **Скасувати** — скасовує замовлення.

### Безпека доступу:
У `.env` можна вказати параметр `TELEGRAM_ALLOWED_USER_IDS=12345678,87654321`. Бот буде відповідати лише авторизованим співробітникам (водіям та власнику бізнесу).

## 🚀 Розгортання на Linux VPS

Додаток спроєктовано для роботи на існуючому сервері без конфліктів з іншими сайтами чи контейнерами:
- Використовує виділене ім'я проєкту `peat_crm`.
- PostgreSQL **не публікує** свої порти назовні (доступний виключно у внутрішній Docker-мережі `peat_network`).
- Дані PostgreSQL зберігаються в іменованому томі `peat_postgres_data`.
- Веб-сервер за замовчуванням прив'язується до локального інтерфейсу `127.0.0.1:8080`, готовий для проксі через Nginx.

### 1. Клонування та налаштування оточення
```bash
git clone https://github.com/varfozel/torfCRM.git
cd torfCRM

# Створіть файл конфігурації з шаблону
cp .env.example .env

# Відредагуйте паролі та токен бота
nano .env
```

Обов'язково вкажіть:
- `POSTGRES_PASSWORD` — надійний пароль до бази.
- `DATABASE_URL` — оновіть пароль у рядку підключення.
- `TELEGRAM_BOT_TOKEN` — токен від [@BotFather](https://t.me/BotFather).
- `TELEGRAM_ALLOWED_USER_IDS` — ID ваших Telegram-акаунтів (через кому).
- `WAREHOUSE_LAT`, `WAREHOUSE_LON` — координати вашого складу/торфовища.

### 2. Запуск контейнерів
```bash
docker compose up -d --build
```
Під час запуску контейнер автоматично виконає міграції Alembic і запустить FastAPI разом із фоновим Telegram-ботом.

### 3. Перевірка статусу
```bash
# Перегляд стану контейнерів
docker compose ps

# Перегляд логів
docker compose logs -f app
```

### 4. Налаштування Nginx (Reverse Proxy) на VPS
Створіть конфігурацію для домену чи піддомену (наприклад, `/etc/nginx/sites-available/peat-crm`):

```nginx
server {
    server_name crm.yourpeatbusiness.ua;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
Активуйте та отримайте безкоштовний SSL-сертифікат Let's Encrypt:
```bash
sudo ln -s /etc/nginx/sites-available/peat-crm /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d crm.yourpeatbusiness.ua
```

## 💾 Резервне копіювання та відновлення (Backup & Restore)

### Ручне створення резервної копії:
```bash
chmod +x ./scripts/backup.sh
./scripts/backup.sh
```
Дамп зберігається в папку `./backups/peat_crm_backup_РРРРММДД_ГГХХСС.dump`. Скрипт автоматично видаляє бекапи, старші за 14 днів.

### Налаштування щоденного бекапу через `cron`:
Відкрийте планувальник завдань на сервері:
```bash
crontab -e
```
Додайте рядок для створення бекапу щоночі о 02:00:
```cron
0 2 * * * /path/to/torfCRM/scripts/backup.sh >> /path/to/torfCRM/backups/backup.log 2>&1
```

### Відновлення бази з дампу:
```bash
chmod +x ./scripts/restore.sh
./scripts/restore.sh ./backups/peat_crm_backup_20261004_120000.dump
```
Скрипт запросить підтвердження, розірве активні з'єднання та безпечно відновить дані.

## 💻 Локальна розробка та тестування

### 1. Створення віртуального оточення та встановлення залежностей:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Запуск тестів:
```powershell
pytest -v
```
Тестовий набір використовує вбудовану асинхронну пам'ять SQLite і перевіряє точність Decimal, валідацію схем, розрахунки доставки, Waze-посилання та Telegram-бот.

### 3. Локальний запуск API:
```powershell
uvicorn app.main:app --reload
```
Документація API буде доступна за адресою: `http://localhost:8000/docs`.

### 4. Локальний запуск бота окремим процесом:
```powershell
python -m app.bot.runner
```
